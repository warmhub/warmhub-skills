# Security Policy

## Reporting a Vulnerability

Please report suspected security vulnerabilities by email to
[security@warmhub.ai](mailto:security@warmhub.ai).

Do not report security issues through public GitHub issues, pull requests,
discussions, or other public channels. If you are unsure whether something is a
security issue, email us and we will help triage it.

When possible, include:

- A description of the vulnerability and its potential impact.
- Steps to reproduce or a proof of concept.
- Affected files, packages, versions, commits, or install paths.
- Any relevant logs, screenshots, or environment details.
- A safe way to contact you for follow-up.

We will review reports sent to the security email address and follow up as
appropriate. Please avoid public disclosure until we have had a reasonable
opportunity to investigate and respond.
